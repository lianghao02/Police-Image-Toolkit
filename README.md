# Police Image Toolkit

Windows 本機手機圖片轉檔與手機螢幕錄影截圖工具。處理影像不需上傳檔案，衍生圖片不能取代原始素材保存。

**原始碼版本：v11.6.0**（含 `2026-11-22` 未另發版之 2D 天青硬邊視覺調校與 `RUN-DEV.bat` 開發啟動器）。本頁描述此原始碼的功能；已發布的執行檔可能較舊，請以 Releases 的版本與說明為準。

## 下載與執行

- [查看已發布版本與下載項目](https://github.com/lianghao02/Police-Image-Toolkit/releases/latest)：在 Assets 選擇 EXE 或 ZIP。
- [下載最新已發布的 EXE](https://github.com/lianghao02/Police-Image-Toolkit/releases/latest/download/PoliceImageToolkit.exe)：此連結跟隨正式 Release，不代表開發中原始碼版本。
- 下載後先確認來源，並與同一 Release 提供的 SHA-256 檔比對：`Get-FileHash .\PoliceImageToolkit.exe -Algorithm SHA256`。
- 若 Windows 顯示 SmartScreen，請依組織政策及來源驗證結果決定是否執行。公開原始碼或雜湊相符並不等於安全保證。

系統需求為 Windows 10／11 x64。正式單檔包內含 .NET Runtime；HEIC、HEIF、WebP 與影片解碼仍依 Windows 可用編解碼器而定，不能保證所有檔案都能開啟。

## 圖片轉檔

1. 拖入圖片或資料夾，或按「加入圖片」／「加入資料夾」。支援 JPG、PNG、BMP、TIFF、單幀 GIF，以及系統可解碼的 HEIC／HEIF／WebP；清單提供縮圖並可點擊預覽原圖。
2. 設定輸出格式、JPG 品質、長邊上限及方向校正。JPG 品質是編碼參數，不是畫質保留百分比。
3. 確認儲存位置後按「開始轉檔」。預設建立來源資料夾下的 `Converted` 子資料夾；同名檔另加流水號，保留原檔與先前輸出。
4. 檢查成功／失敗數量及來源紀錄。失敗項目可再按開始重試；要以新設定重新轉換，按「依設定重轉」。

轉檔開始後固定整批設定。停止轉檔會保留已完成檔案及其來源紀錄，未完成項目可接續處理。來源紀錄更新失敗時，按「重試來源紀錄」。

多頁 TIFF、動畫 GIF 及其他多影格圖片會明確拒絕，避免只匯出第一頁而遺漏內容。請先使用合適工具逐頁匯出。超大圖有像素上限與併行限制，但無法保證所有編解碼器在低記憶體電腦上都能處理。

## 手機錄影截圖

影片功能只用來從手機螢幕錄影逐張擷取手機畫面。保留直式手機框並提供「目前影片畫面」與「上一張截圖對照」雙直式並排工作台，方便人工核對接縫。

1. 開啟或拖入手機螢幕錄影，等待載入完成；載入多支影片時可從頂部「切換分段」下拉選單切回先前錄影。
2. 確認底部儲存位置；可變更路徑。每部影片使用「來源檔名_Snapshots_來源識別碼」子資料夾；同名但位於不同來源位置的錄影分開儲存。識別碼依來源位置產生，不是影片內容雜湊。
3. 播放（支援 `1x / 1.5x / 2x` 倍速）或以按鈕、快捷鍵、滑鼠滾輪微調位置，畫面穩定後按「擷取目前畫面（Space）」。截圖依視訊軌解析度輸出，手機框大小不影響輸出像素。
4. 在右側並排對照框切換「整張／底部／頂部」或開啟非模態「原圖」視窗人工確認沒有漏截；右側清單支援點選指定截圖預覽及單張移至回收區。

| 快捷鍵／操作 | 動作 |
|---|---|
| Space | 擷取目前畫面；輸入文字、操作下拉選單或滑桿時停用（剛微調後會自動等待畫面穩定再截） |
| ←／→ 或 A／D、手機框滾輪 | 後退／前進 0.1 秒（長按可連續微調） |
| Shift + ←／→ 或 Shift + 滾輪 | 後退／前進 0.5 秒 |
| ↓／↑ 或 S／W | 後退／前進 1 秒（長按可連續微調） |
| P 或 Enter | 播放／暫停（焦點在按鈕上時 Enter 保留原生點擊） |
| Ctrl + Z | 將目前清單最新一張截圖移至暫存回收區 |
| Esc（於前綴輸入框內） | 退出文字輸入焦點並恢復快捷鍵 |

**時間限制**：0.1 秒是時間步進，不是一個影格。介面、索引與浮水印使用播放器回報位置，並非解碼影格的精確 PTS；定位等待只能降低快速移動後截到舊畫面的風險。需要逐影格或法律鑑定等級時間精度時，請使用可驗證影格與時間戳的專用工具。

預設不加浮水印。開啟後，影片時間與檔名會直接寫入衍生圖片；原始影片不變。

## 換到第二段手機錄影

- 開啟下一段後，從片頭開始；清單與數量只顯示目前這段。
- 第一張截圖前保留「上一段最後截圖（參考）」，附來源檔名與時間，方便人工確認接續位置。這不代表工具已判斷兩段內容相同；可按「關閉」移除參考，不影響原圖。
- 儲存這段第一張後，對照區改成目前影片上一張；若移除目前清單全部截圖，仍可查看保留的上段對照。
- Ctrl + Z、單張移除、全部移至回收區、還原、清空清單及索引重試，都只操作目前這段。第二段還沒有截圖時，Ctrl + Z 停用。
- 格式與品質沿用；上次停留分頁亦會記憶。新影片前綴預設留白；儲存主位置沿用並常駐顯示。重新開啟本次已處理的影片，會恢復自己的清單、前綴、儲存主位置及來源紀錄提示。
- 每段的工作清單與設定只在本次開啟程式期間保留，不會在重啟後自動載回。舊版的 `_Snapshots` 資料夾及檔案保留，不會搬動或合併到新資料夾。

## 移除、回收與還原

- 「清空清單」只清除目前影片的介面清單，不移除磁碟檔案。
- 「移至回收區」將衍生截圖搬到同輸出資料夾的 `.pit-recovery`，不永久刪除，也不操作原始影片；後續新截圖流水號會自既有最大編號之後遞增，不補佔已移除的空號。
- 「還原最近移除」只還原目前影片在本次工作中的回收檔，並依時間與檔名序插回清單原位置；同名檔已存在時會拒絕覆寫並保留回收檔。
- 若目前資料夾存在 `.pit-recovery` 暫存檔，底部工具列會顯示「開啟回收區」與「清空回收區」供檢視或永久清理；程式不會自動清空。

## 來源紀錄與隱私

輸出資料夾內的 `report_index.json` 保存輸出檔名、來源檔名、工具類型、影片播放位置與像素尺寸，不保存來源絕對路徑或自行推斷案號。來源檔名本身仍可能含個資，分享輸出前請檢查。

索引寫入使用原子替換與跨程序鎖；鎖檔集中存放於 `%LOCALAPPDATA%\PoliceImageToolkit\locks\`，不在輸出資料夾產生 `.report_index.lock`。無法取得鎖或既有索引格式不相容時，保留影像並顯示重試提示。人工移動或還原磁碟檔案不會自動同步索引。

所有影像運算在本機進行。只有手動點擊「檢查更新」並確認後，才會向 GitHub 查詢公開發行資訊；不會上傳來源檔案。偏好設定（`%LOCALAPPDATA%\PoliceImageToolkit\settings.json`）只記錄格式、品質、開關與上次停留分頁，不記錄檔案路徑；未預期錯誤日誌寫入 `%LOCALAPPDATA%\PoliceImageToolkit\crash.log`，回報前請去識別。

## 開發與驗證

使用 .NET 8 SDK；Windows WPF 核心測試是自訂主控台程式，不能以 `dotnet test` 沒報錯作為通過證據。

```powershell
# Windows：實際執行核心回歸測試
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\test.ps1
# Windows：格式、敏感值掃描、WPF 建置與核心測試
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\qa.ps1
# Windows：QA 通過後建立免安裝單檔與 SHA256SUMS.txt
.\BUILD.bat
# Windows/Linux：跨程序索引整合測試
dotnet run --project tests/PoliceImageToolkit.IndexTests -c Release
```

Windows 自動檢查見 `.github/workflows/windows-qa.yml`。本次修訂項目、驗證證據及待驗收項目見 [修訂與驗收紀錄](docs/REVISION_REVIEW.md)。
