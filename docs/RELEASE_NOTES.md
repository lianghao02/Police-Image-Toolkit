手機螢幕錄影截圖與圖片轉檔 v11.6.0 正式版。重構雙直式預覽對照工作台，並強化微調操控、記憶體控管與索引防損機制。

- **雙直式並排工作台與接縫核對**：影片畫面左側固定為「目前影片畫面」，右側改為「上一張截圖」並排顯示；對照框支援「整張／底部 1/3／頂部 1/3」切換與非模態「原圖」視窗（支援雙擊或 Esc 關閉）；右側清單加入縮圖載入，支援點選指定截圖即時預覽與單張移至回收區，並新增「切換分段」按鈕選單。
- **操控精度與長作業記憶體優化**：新增 `±0.5 秒` 快速微調（`Shift + ←/→`）與 `1x / 1.5x / 2x` 播放倍速切換；影片框支援滑鼠滾輪微調 `±0.1 秒`（`Shift + 滾輪` 為 `0.5 秒`）；復原快捷鍵調整為 `Ctrl + Z`，修正長按連續微調延遲及輸入時誤觸空白鍵截圖；對照全圖／1/3 裁切改為按需單張生成與釋放，降低長作業記憶體占用。
- **效能、防呆與輸出資料夾**：支援系統原生流暢載入輸出資料夾圖片，`.pit-recovery` 支援最大數量限制與自動清理；`.report_index.lock` 移至 `%LOCALAPPDATA%\PoliceImageToolkit\locks\` 保持輸出目錄乾淨；新增檔案總管右鍵「開啟檔案位置」。
- **圖片轉檔與介面一致性**：圖片轉檔新增「開啟資料夾」按鈕與完整縮圖／原圖預覽；修正全局色票與多行錯誤文字折行；記憶上次關閉分頁（`LastTabIndex`）；`crash.log` 改寫入 `%LOCALAPPDATA%\PoliceImageToolkit\crash.log`。

自動測試與建置驗收：Windows QA 通過、核心服務測試 `25/25` 通過、來源紀錄整合測試 `5/5` 通過，並已完成單檔 Self-Contained x64 執行檔建置。自動測試不等於完成所有實機畫面、HEIC/影片解碼器與人工無障礙驗收。

注意事項：

- 影片截圖、分頁位置與播放倍速等介面操作仍建議於實機以真實手機螢幕錄影操作確認。
- 回收區檔案位於 `.pit-recovery`，重開程式後仍在，超過上限將依時間順序清理最舊項目。
- 0.1 秒為時間步進，播放器回報位置不保證精確影格時間。所有截圖內容與銜接處仍需人工確認。
- 下載後請用同一發行版本的 SHA-256 清單核對 EXE 或 ZIP。
