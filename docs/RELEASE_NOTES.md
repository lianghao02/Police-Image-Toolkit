手機螢幕錄影截圖與圖片轉檔 v11.7.0 正式版。導入 2D 日系動漫天青視覺風格與深警務藍標題列，並補強轉檔 EXIF／ICC 保留、縮圖防鎖檔與多螢幕視窗支援。

- **介面視覺風格與啟動體驗**：加入深警務藍標題列與降眩光冷灰藍分層色調，於 `App.xaml`／`MainWindow.xaml`／預覽視窗統一套用 2D 日系動漫天青硬邊風格；新增 `RUN-DEV.bat` 開發啟動入口。
- **轉檔色彩保真與 EXIF 保留**：`ImageService` 轉檔解碼優先保留 ICC 色彩描述檔（異常時安全退回），JPG／TIFF 輸出保留關鍵 EXIF 拍攝時間與機型並於自動旋轉後將 `Orientation` 歸正為 `1`；原圖預覽套用 Exif 自動轉正。
- **穩定性與多螢幕支援**：背景縮圖載入加入 `CancellationTokenSource` 取消與 `FileShare.ReadWrite | FileShare.Delete`，根除清空清單時偶發鎖檔；移除視窗載入寫死的 `MaxWidth`／`MaxHeight`，支援外接大螢幕自由放大。

自動測試與建置驗收：Windows QA 通過、核心服務測試 `27/27` 通過、來源紀錄整合測試 `5/5` 通過，並已完成單檔 Self-Contained x64 執行檔建置。自動測試不等於完成所有實機畫面、HEIC／影片解碼器與人工無障礙驗收。

注意事項：

- 影片截圖、分頁位置與播放倍速等介面操作仍建議於實機以真實手機螢幕錄影操作確認。
- 回收區檔案位於 `.pit-recovery`，重開程式後仍在，超過上限將依時間順序清理最舊項目。
- 0.1 秒為時間步進，播放器回報位置不保證精確影格時間。所有截圖內容與銜接處仍需人工確認。
- 下載後請用同一發行版本的 SHA-256 清單核對 EXE 或 ZIP。
