手機螢幕錄影截圖與圖片轉檔修訂版。影片流程維持人工檢視、手動截圖，保留直式手機框。

- 第二段第一張截圖前保留並標示上一段最後截圖；本段有截圖後切換成本段對照。
- 每段獨立的清單、數量、前綴、儲存位置與來源紀錄；Z、整批移除及還原限定目前影片。
- 同名但位於不同來源位置的手機錄影分開輸出，不混用資料夾。
- 修正背景存檔換片的來源錯置、取消轉檔漏建索引與多程序索引覆寫；多頁影像明確拒絕，避免靜默漏頁。
- 統一介面文字與按鈕層級；儲存成功才顯示成功回饋，來源紀錄可重試，移除截圖可由回收區還原。

此發行流程必須通過 Windows QA、21 項核心測試與 5 項整合測試後才建置、上傳並公開資產。自動測試不等於完成所有實機畫面、解碼器與無障礙驗收。

注意事項：

- 新輸出資料夾名稱包含來源位置識別碼；舊版資料夾與檔案保留，不自動搬移。識別碼不是影片內容雜湊。
- 分段工作清單與還原清單只在本次開啟程式期間保留。回收區檔案位於 `.pit-recovery`，重開程式後仍在，但需人工恢復。
- 0.1 秒為時間步進，播放器回報位置不保證精確影格時間。所有截圖內容與銜接處仍需人工確認。
- 影像處理在本機完成；HEIC、HEIF、WebP 與影片解碼依 Windows 可用編解碼器而定。
- 下載後請用同一發行版本的 SHA-256 清單核對 EXE 或 ZIP。
