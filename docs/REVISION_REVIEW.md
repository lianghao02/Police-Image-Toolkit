- 每段獨立的清單、數量、前綴、儲存主位置及來源紀錄提示；本次工作中重新開啟同一來源可以取回。
- 保留上一段最後截圖並明示來源與時間，可手動關閉；本段第一張成功後轉成本段對照。
- Z、整批移除、還原、移除清單及來源紀錄重試都限定目前影片。
- 移除或還原同步期間阻擋換片；背景截圖存檔仍可換片，結果回原影片清單。
- 同名不同來源位置使用獨立資料夾；識別碼不是影片內容雜湊，舊輸出不搬動。
- Windows CoreTests 新增三個案例，合計 21 個；GitHub Windows CI 已實際執行 21/21 通過，整合測試 5/5 通過。

## Windows 操作驗收清單

1. 開啟程式：檢查 960×640、1366×768、1920×1080 及 100%／125%／150% 縮放；內容可捲動到達，主操作與焦點可辨。
2. 圖片轉檔：加入各種來源格式，調整設定並開始；確認原檔雜湊不變、同名另存、成功／失敗與來源紀錄分開顯示。
3. 部分完成後停止：確認完成圖片與索引保留，可繼續未完成項目；重新轉檔會另存並先確認。
4. 模擬索引寫入失敗：保留圖片，解除權限或檔案格式問題後可重試；清空清單後仍保有未完成索引的重試資料。
5. 載入直式手機螢幕錄影：確認手機框完整、內容可辨識；讀取中不能截圖，來源標示正確。
6. 快速移動／換片／截圖：確認沒有新舊工作結果錯置；以帶逐格編號影片衡量時間限制，不把短暫等待視為精確解碼保證。
7. 鍵盤導覽：測試文字框、下拉、滑桿、勾選框、按鈕焦點與 Space／Enter；無誤截或重複移除。
8. 截圖結果：只有成功存檔後才有成功回饋；檢查底部文字對照、原尺寸預覽、來源紀錄及輸出位置。
9. 移除／還原：檢查回收檔保留、單張與整批移除、同名檔保護、來源紀錄同步及失敗重試。關閉程式後手動恢復回收檔的限制須與說明一致。
10. 連續處理第一段、第二段：檢查上段對照、來源標示、首張後更新、本段計數、Z／整批移除／還原範圍；切回第一段後清單與設定仍在。測試同名但不同位置錄影，以及背景存檔中換片。
11. 執行 `scripts/qa.ps1`：確認 CoreTests 21/21 與 IndexTests 5/5；再執行 BUILD.bat，核對單檔、雜湊與說明文件。

## 已知邊界

- 這是報告素材整理工具，來源紀錄不是證據完整性或司法鑑定的替代品。
- 影片時間使用 WPF MediaPlayer 回報位置，沒有加入新的解碼引擎，不提供逐影格精確 PTS 保證。
- Windows 解碼器、低記憶體行為、遠端磁碟鎖及不同 DPI 行為需要實機測試。
- 回收區不自動清理，重開程式後本次還原清單不保存；磁碟中的回收檔仍保留。
- 同名來源僅靠檔名不能提供內容唯一性；需要完整鑑識證據鏈時應另外保存來源雜湊與原始檔。

- 分段工作清單與設定不跨程式重啟保存，既有輸出不會自動匯入清單。
