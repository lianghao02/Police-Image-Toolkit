# 介面用語與樣式規範

## 用語

| 概念 | 使用文字 | 避免文字 |
|---|---|---|
| 圖片轉換 | 圖片轉檔、開始轉檔、依設定重新轉檔 | 重設狀態、秒轉、保證支援所有格式 |
| 影片畫面 | 截圖、儲存目前畫面、上一張截圖 | 當前頁、快照、已擷取證物 |
| 操作時間 | 移動 0.1 秒、播放器回報位置 | 精準逐格、毫秒精確 |
| 索引 | 來源紀錄、重試來源紀錄 | 前端直接顯示索引實作細節 |
| 移除介面項目 | 移除本段清單（保留檔案） | 讓使用者猜測是否會刪檔 |
| 可還原移除 | 移至回收區、還原本段最近移除 | 復原／刪除、永久刪除但稱復原 |
| 尺寸與品質 | 寬 × 高、JPG 品質數值 | 以寬度表示 1080p、品質保留百分比 |

## 樣式

- 主操作使用藍底白字；同一工作區只突出主要執行動作。
- 次要操作使用白底、細框與深色文字。移至回收區的整批操作使用紅色並明確確認。
- 按鈕有 hover、pressed、disabled 與 keyboard focus 狀態。焦點以高辨識邊框顯示，不能只靠滑鼠 hover。
- 標題、表單標籤、提示與結果分層；重要結果與儲存位置不可只留在 Tooltip 或省略號內。
- 確認圖片已儲存後才能提供成功回饋；來源紀錄更新結果獨立顯示並可重試。
- 手機錄影截圖保留直式手機框（340 × 540 設計尺寸，依工作區等比例縮放）；對照區保留底部內容及原尺寸查看入口。此功能只服務手機畫面擷取，不增加橫式影片或通用播放器模式。
- 表單提供可辨識的控制項名稱；影片時間滑桿保留鍵盤操作。實際螢幕閱讀器及高對比模式仍需驗收。

## 分段錄影交接

- 清單標示「本段截圖」；移除、還原與來源紀錄重試限定目前影片。
- 跨段對照必須標示「上一段最後截圖」及來源、時間，可手動關閉，不能假設內容已連續。
- 本段有截圖後顯示「本段上一張截圖」；分開儲存不代表自動擷取或自動判讀。
- 新影片前綴留白，格式品質沿用；換回已處理影片恢復其前綴與位置。
